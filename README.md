# Grok Bot timeline

A single-page, self-contained DAW/Gantt-style weekly timeline of Per Larsen's Grok Bot fleet,
in a Brunello Cucinelli–inspired palette.

**Live:** https://perkalars211.github.io/grok-bot-timeline/

- Buses (Commercial / Private / Meta / Archived) fold by clicking their header.
- Zoom with **D** (day) / **W** (week), **N** jumps to the now line; M/S mute/solo per track; hover a clip for details.
- All clips are **demo data** (illustrative, not live activity).

No build step or server: just `index.html` with embedded CSS/JS.
